## 如何继续学习

在仓库根目录打开会话，直接说：

> 继续学习。

助手会按 `docs/learning-workflow.md` 读取最新检查点，一句话告知恢复位置并直接开始。时间紧张时可说明“继续学习，今天有 30 分钟”；W16 模拟盘上线后，可直接说“巡检模拟盘”；暂停时说“今天先到这里，保存进度”。

## 阶段结构总览

- **W01–W10（已完成）**：投资与市场基础、美股交易微结构、财务估值、资产配置、日频数据与 2025 测试集封存、统计与随机性、买入持有基准、均线账本（以及原 MLF-W01/W02 因子基础）。
- **W11–W15（核心攻坚，验证与模拟盘就绪）**：切换 `pandas/numpy` 并补统计速成 → 跨资产 ETF 池与长周期数据（真实 $R_f$）→ 亲手编写目标权重含成本回测与同口径基准 → 动量/趋势防守策略与稳健性 → 滚动验证、DSR/PBO 与波动率风控 → 模拟盘工程、故障演练与税务校准。
- **W16–W21（模拟上线 + 组合进阶 + 现代 ML 多因子）**：**W16 正式上线前向模拟盘** + 多策略组合与因子回归归因 → 横截面单因子 IC/Rank IC 与泄漏排查 → 中性化与 OLS/Ridge 基线 → **LightGBM/GBDT 树模型与 SHAP 解释** → 严格滚动验证与换手成本 → **W21 一次性解封最终测试集**。
- **W22–W24（审计与结业）**：模拟盘深度复盘与一键复现审计 → 跨资产 ETF 与 ML 多因子双报告对比 → 约 9 周模拟盘终盘答辩与个人投资路线图。

## 数据追踪与安全边界

- `.gitignore` 对 `data/` 默认忽略，仅逐项放行小型虚构教学样本及已声明的教学数据（如 SPY 教学 NAV 样本）；`.gitattributes` 保留数据文件原始字节以保障 SHA-256 一致性。
- `data/sealed/` 为封存测试目录，在 W21 解封条件满足前严禁读取用于研究或输出行情统计。
- 所有策略与模拟脚本默认采用模拟/dry-run 模式，不连接真实资金账户。
