# 虚构教学数据

本目录只存放可公开复现的小型教学数据，所有数值均为教师构造，不是从行情提供商下载的真实历史记录，也不能用来评价策略。

## daily_demo.csv

- 用途：W07D01，用Python标准库读取日频CSV并复现手算。
- 来源：教师构造，2026-11-08；D1沿用A组题目，D0除已给的收盘价50外，其余字段由教师补齐用于演示文件结构。
- 获取日期：不适用，未下载真实行情；以上日期为编写日期。
- 资产：单只虚构教学ETF，不对应真实证券代码。
- 区间与频率：D0、D1两个相邻的虚构交易日；每天一行。
- 日期与时区：date列保留D0/D1占位字符串，按假定美国东部交易当地日期理解，无真实日历映射；不是可直接解析的日期时间，也不是下载日期。
- 交易范围：假定常规交易时段内全部纳入本例的成交；不代表任何真实数据源的覆盖范围。
- 单位：open/high/low/close为美元/份；volume为成交份数，非个人持仓或成交金额。
- 价格口径：虚构的未调整成交价格；没有分红、拆股、税费或汇率变化，收益示范无资金进出。
- 文件格式：UTF-8，无BOM；英文逗号分隔，首行为字段名；数值文本不带货币符号或千位逗号。
- 顺序：第一条D0，第二条D1。读取函数保持文件原顺序，不自动按日期排序。
- 缺失与重复：本文件没有缺失或重复；本课脚本不填充、删除或推断它们，真实数据质量检查留待后续课。
- 数据集边界：教学样本不属于未来的真实开发集或最终测试集；真实样本的选择、下载与测试区间封存均尚未完成。

| 字段 | 本例定义 | 单位或类型 |
| --- | --- | --- |
| date | 交易日占位标签 | 字符串D0/D1 |
| open | 统计时段第一笔成交价 | 美元/份 |
| high | 统计时段最高成交价 | 美元/份 |
| low | 统计时段最低成交价 | 美元/份 |
| close | 统计时段最后一笔成交价 | 美元/份 |
| volume | 统计时段累计成交份数，单边计数 | 份 |

读取流程：在仓库根目录运行`python -B src/read_daily.py`。CSV保存的是文本，`csv.DictReader`默认将字段值读取为字符串；程序显式转换用于计算的收盘价和成交量，日期标签保持字符串。
