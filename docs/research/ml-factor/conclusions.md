| 数据范围 | 股票范围及逐期纳入规则、起止时间、时区、频率、字段单位、复权及分红处理、退市和缺失值规则、数据版本 |
| 特征 | 字段名、定义、变换、观测时点、实际可获得时点、滞后规则；未知可得性及其限制 |

| 结论与限制 | 证据支持什么、不能支持什么；数据偏差、调参次数和与官方结果的差异，是否可推广尚待验证 |

## 第8周报告预留结构

1. 研究问题、官方参考与本次缩小后的范围。
2. 数据来源、字段、时间链、合法使用依据及未知事项。
3. 单因子、线性模型、基准与时间顺序验证方法。
4. 参数冻结、所有尝试、毛收益与成本后结果；至少包含收益、回撤、波动、风险调整表现、换手和假设交易次数。
5. 与官方实现的差异、失败结果、偏差和不确定性。
6. 用户独立解释：结果意味着什么、哪些结论不能下、下一步还需要什么证据。
7. 可重现命令、环境/代码/数据版本及是否继续第二阶段的理由。
