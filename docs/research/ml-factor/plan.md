入口：[研究进度与续学检查点](progress.md)｜[官方材料与环境核查](materials.md)｜[实验记录与结论](conclusions.md)。

## 定位与范围

本项目在GoodLucky原24周课程之外，每周预算约60分钟，先试行8周，预算合计480分钟。预算不等于实际学习时长，也不代表已安排具体日期或提醒。主线原每周5小时的计划保持不变；副线使用独立编号MLF-W01至MLF-W08，不对应主线周次，不自动抵扣或推进主线课程。

目标是完成一个小范围、能够解释和重现的方法复现实验：理解公司特征如何形成排序信号，比较单因子排序与简单线性模型，并检查时间顺序、交易成本和结论边界。这不是在8小时内复现全书、证明策略有效或完成投资训练。

- 优先使用作者官方Python材料。记录与官方实现的每一项实质差异，区分“方法复现”和“数值完全复现”。
- 主线仍以日频、低频、无杠杆ETF研究为后续方向；副线使用书中月频股票材料理解方法，两者的资产范围和假设分别记录。
- 前8周不接入真实交易账户，不使用真实资金，不将结果直接用于交易决策。所有组合与成本均属于历史研究或明确标记的教学模拟。
- 不以正收益作为验收标准。没有改善、成本抵消收益或数据不足以支持结论，均可成为有效研究发现。
- Codex先解释用途、机制和概念关系，完整示范小例子，再让用户计算、操作与解释。代码运行成功不替代用户掌握证据。

## 每周任务与验收

第1至第7周原则上分配为：10分钟复习与问题确认、15分钟讲解及完整示范、25分钟共同复现与用户练习、10分钟独立解释和反馈。第8周为10分钟冻结检查、15分钟重运行、25分钟整理报告、10分钟独立说明。各周均预算60分钟；若核心内容未完成，记录断点并顺延，不因时间用完而标记通过。

| 周次 | 约60分钟的任务 | 预期产出 | 用户验收证据 |
| --- | --- | --- | --- |
| MLF-W01 | 理解公司特征、排序信号与因子组合；阅读官方材料核查，提出一个可检验问题 | 研究问题卡、一个手算排序例子、资料与待核实事项清单 | 能区分输入特征与未来收益标签，说明排序不保证盈利；解释本项目能检验什么、不能检验什么 |
| MLF-W02 | 核实数据使用条件与格式，选择兼容的隔离Python环境；读取少量字段和样本，建立数据字典与时间划分 | 实际环境版本、数据来源及哈希、字段和时点表、预先登记的训练/验证/测试区间 | 能解释一行数据、单位、标签对应期间，以及哪些信息在决策时可能尚不可得 |
| MLF-W03 | 用一个特征逐月排序，分为三组；先手算一期，再运行开发区间内的等权组合 | 单因子排序结果、同股票池等权基准、一期手算与代码核对 | 能解释分组、权重、组合收益和比较基准；不把高低组差值当作已执行的交易 |
| MLF-W04 | 检查重复行、缺失值、字段单位、可获得时点和未来信息泄漏；在开发数据中修正一处示例问题 | 数据检查表、处理规则、修正前后差异记录 | 能指出使用未来收益作输入、按未来完整历史筛股票或使用未来数据拟合处理规则的问题 |
| MLF-W05 | 解释预测值与实际收益的关系，建立普通线性回归基线；时间允许再加岭回归 | 少量特征的模型、常数预测基线、参数记录及开发区间比较 | 能说清特征、标签、拟合、预测各是什么，并解释预测误差与组合收益不是同一指标 |
| MLF-W06 | 按月份顺序做验证；保证训练标签已可获得，限制参数尝试并冻结模型 | 时间划分图、验证结果、参数选择理由与冻结记录 | 能解释为什么不能随机拆股票月份，为什么测试集不能用于选模型，以及边界标签怎样处理 |
| MLF-W07 | 在验证区间计算换手与成本敏感性；统一排序组合、模型组合和基准的交易假设 | 毛收益/净收益对照、交易额和成本手算、冻结的成本方案 | 能解释成本从哪里扣、初始建仓和换仓怎样计数，以及忽略成本可能改变结论 |
| MLF-W08 | 完成冻结检查后仅作一次最终测试；重运行并形成研究报告，决定是否继续试验 | 可重现命令、最终结果表、研究报告、用户独立结论 | 用户独立说明问题、方法、证据、局限与下一步；结果好坏不作为是否通过的标准 |

每周完成要求同时包括产出、必要的计算核对和用户解释。可跳过岭回归、多特征扩展及美化图表等选做项，不能跳过数据来源、时间顺序、成本和结论解释。前置概念不熟时在副线内补讲并记录，不将主线尚未学习的内容视作已掌握。

## 拟议最小实验（尚未执行）

以下是待MLF-W02核对字段与覆盖范围后、查看表现前固定的研究设定。它们不是已验证的数据事实或实验结论。

| 项目 | 拟议设定 |
| --- | --- |
| 数据 | 作者公开材料所描述的美国股票月频样本；仅使用合法可用的来源，原始数据保留并记录哈希，不提交原始数据到仓库 |
| 范围 | 优先研究2010–2018年，按每月当时满足条件的股票构建样本；只读取必要字段，不按未来是否持续存在筛选股票 |
| 单因子 | 候选字段Mom_11M_Usd；准确含义、单位、处理方式与可获得时点先核对，不凭名称推断 |
| 模型 | 普通线性回归为必做；最多3个特征，候选另含Vol1Y_Usd、Mkt_Cap_12M_Usd。岭回归为选做，参数候选最多3个并预先登记 |
| 标签 | 候选R1M_Usd。官方说明它是已对齐的未来一个月总收益；核对单位和起止时间后使用，不将未来收益列混入特征 |
| 时间划分 | 候选训练2010–2013年、验证2014–2015年、测试2016–2018年；按月份整体分组，留足特征历史和标签尾部，边界按标签实际可获得时间调整 |
| 组合 | 每月按特征或预测值分为三组，研究高组等权、无杠杆、只做多的假设组合；低组及高减低仅作诊断，不默认卖空交易 |
| 基准 | 同区间、同可投资范围的等权组合；预测任务另设常数预测基线。所有比较使用相同收益与成本口径 |
| 成本 | 0、10、25个基点的每单位成交金额成本情景，均为教学假设，不代表券商报价。1个基点为0.01% |

执行时必须遵守：

1. **先确认数据条件。** 公开可下载不自动证明可以任意使用或再分发。先查使用说明、来源和适用范围；无法确认合法使用时不获取该数据，可用明确标为合成的小表讲机制，但真实数据复现仍记为待完成。格式转换另存，不覆盖原始文件。
2. **先固定划分，再比较表现。** 第2周登记区间，开发使用训练与验证数据；测试集不用于选字段、处理规则、模型、成本参数或图表。第6至7周完成冻结，第8周才评估最终测试。记录测试接触情况；看过结果后修改方案，不能再称原测试集为未见数据。
3. **记录完整时间链。** 记录特征观测与实际可获得时点、预测时点、标签起止及可获得时点、假设执行时点。只用拟合时已经揭晓的训练标签；边界重叠样本按实际期间剔除，不能仅机械空出一行。
4. **不把未知时点包装成已验证。** 若无法证明特征当时可得，可登记至少滞后一期的敏感性假设；滞后不证明已消除财报修订和幸存者偏差。仅凭月频数据不能声称按次日开盘价真实可成交；证据不足时结论限于方法演示或统计关系。
5. **处理规则也有训练边界。** 数据列按名称选择；拟合型填补、缩放和模型只在对应训练窗口拟合。保留原始数据和变更记录；不默默将缺失收益设为0，不因未来数据齐全而筛选样本。按月形成排序时，不利用该月未来收益决定分组。
6. **把交易额说清楚。** 成本金额按股票买入金额与卖出金额之和乘成本率计算；记录以净值为分母的比例，若另报“单边换手率”则注明是否除以2，避免再重复扣费。考虑价格变动后的权重、初始建仓和退出；没有数据支撑的流动性或退市处理明确列为限制。
7. **口径一致。** 总收益标签中的分红不重复加计。月频年化因子为12，波动率年化用平方根12；若风险调整指标暂假定无风险收益为0，必须注明这只是研究假设。
8. **报告全部尝试。** 保存参数、随机种子（若使用随机过程）、版本、失败结果及与官方实现的差异。不得只展示收益最好的一次或将历史收益写成真实交易收益。

## 环境与文件边界

本轮仅静态检查官方网页、代码文本、仓库元数据和本机解释器信息；未安装依赖、下载原始数据或运行实验。具体证据见[材料核查](materials.md)。

后续按需创建隔离环境与小脚本，优先numpy、pandas、matplotlib、scikit-learn及必要的传递依赖。数据格式确定后只增加所需的一个读取适配器；不预装深度学习、XGBoost或贝叶斯调参工具。选定兼容环境后再记录实际依赖版本，避免升级主线使用的全局环境。

研究代码、数据、产物如需创建，应分别置于项目专用子目录，例如`src/research/ml_factor/`、`data/ml-factor/`、`reports/ml-factor/`，届时同步忽略原始数据、缓存和本地环境。现在不创建这些目录或空框架。
