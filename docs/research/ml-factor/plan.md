## 定位与升级点

本项目以 Guillaume Coqueret & Tony Guida《*Machine Learning for Factor Investing: Python Version*》[官方 Python 材料](https://www.mlfactor.com/python.html)为方法起点，并在 v2.0 中针对原 8 周方案的局限（数据停留在 2019 年、仅做 3 特征 OLS 缺乏现代树模型、缺少因子 IC 体系）进行了实战升级：

1. **完整承接已完成成果**：MLF-W01 与 MLF-W02 的验收证据、作者 `data_ml.RData` 固定版本校验及 2010–2013 训练 / 2014–2015 验证 / 2016–2018 最终测试的预登记边界全部保留，不重做。
2. **补齐现代横截面因子评估与模型**：
   - 补入核心因子诊断指标：**IC / Rank IC / ICIR 与因子衰减分析**；
   - 补入**横截面去极值、标准化与市值/行业中性化直觉**；
   - 在 OLS/Ridge 线性基线之后，新增现代横截面真正主力的**梯度提升树（LightGBM / HistGradientBoosting）+ 特征重要性 / SHAP 解释**；
   - 明确作者 1998–2019 匿名数据集的时效与 PIT（Point-in-Time）边界，并讨论 2019 年后公开因子拥挤与市场结构变化。
3. **统一代码分工**：由学习者主导编写因子排序、IC 计算、分组收益、滚动窗口切分与换手成本逻辑，AI 负责数据读取骨架、边界测试与代码审查。

## 预登记研究设定（保留原有纪律）

以下预登记设定在 W17–W21 实证阶段继续有效，防止窥探测试集：

- **固定原件**：作者 `material/data_ml.RData`（commit `572b22acd4dbf58ef9a6dadbdcd976344d3af1d4`，本地 SHA-256 及核验记录见 [materials.md](materials.md#mlf-w02-author-sample)）。
- **预登记观察月划分**：训练 **2010–2013**、验证 **2014–2015**、最终测试 **2016–2018**（进入下一段前严格剔除收益期间跨越边界的标签）。
- **核心候选字段**：`Mom_11M_Usd`、`Vol1Y_Usd`、`Mkt_Cap_12M_Usd` 及少量经预先登记补充的基本面/估值特征；标签 `R1M_Usd`（含分红下月总收益，严禁混入特征）。
- **组合与成本口径**：按月分层，研究高组等权、无杠杆、只做多组合（高低差与 IC 作诊断）；基准为同股票池等权组合；检验 0、10、25 bps 双边成交额成本情景，不将缺失收益静默填 0。
- **不以正收益作验收标准**：若扣费后优势消失或树模型未显著超越简单排序/线性基线，均作为真实有效研究结论记录于 [conclusions.md](conclusions.md)。
