## 字段与使用边界

| 字段 | 含义 | 单位与类型 |
| --- | --- | --- |
| date | 来源Date所标净值日期 | CSV文本YYYY-MM-DD，读取后为Python date |
| nav | 来源NAV，每份基金净资产价值 | 美元/份；CSV文本，读取后为float，空白保留为None |
| source_row | 原始navhist工作表行号 | 整数；排序后保持随同一条记录移动 |

这是发行人发布的每日每份净值，不是交易所close、盘中可成交报价或含分红再投资的总回报指数。NAV描述基金净资产除以份额；市场买卖价格可以不同。程序没有实施前复权、后复权或分红再投资，也不能仅凭此表推定某段没有分红。来源字段为日期，不带时分秒或时区；课堂按发行人美国业务净值日期使用，具体估值时刻、发布延迟及历史修订时间未在本文件核实，不能用于模拟当时何时可获知数据。

频率为来源日频，仅有Date/NAV，没有OHLCV完整行情。样本已有五行均能解析，未发现重复日期或空白NAV；这不是交易日历完整性验收。未独立校验预期交易日集合，不能用“无空白”证明没有缺整行。后续W07D04须核验相应日历与覆盖范围。

原始文件包含更长历史，工具为辨认布局曾显示首页近期数据；课堂只列上述窗口，没有绘图、评估策略或划定最终测试区间。已查看的样本和近期字段不得作为全新未见数据；正式研究池、行情源、开发和最终测试区间仍待单独确定。本份NAV快照不是已封存的最终测试集。
