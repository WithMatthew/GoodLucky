## 来源与获取方式

采用Yahoo Finance公开日频图表JSON响应，端点为`https://query1.finance.yahoo.com/v8/finance/chart/{symbol}`。本次六个请求均无需登录、API密钥或付费，原始响应完整保留；使用`interval=1d`、`includePrePost=false`、`includeAdjustedClose=true`并请求公司行动。起止日期按America/New_York转换为时间戳，接口结束边界使用指定末日的次日零点，再逐行拒绝区间外记录。

这是本次实测可访问的图表端点，不是Yahoo保证稳定的正式开发者API；不能承诺以后持续可用。Yahoo的[历史数据CSV下载帮助](https://help.yahoo.com/kb/search-app-for-ios/download-historical-data-yahoo-finance-sln2311.html)将网页下载功能列为Gold订阅功能；本次没有使用该CSV下载功能、账户或订阅。[免费方案说明](https://help.yahoo.com/kb/SLN36623.html)列有图表和市场数据。两者应区分，不能把本次接口成功概括成“所有Yahoo历史下载都免费”。

来源说明核验于2026-11-14：[Yahoo数据供应商说明](https://help.yahoo.com/kb/yahoo-finance-plus/partnerships-sln2310.html)。本项目使用的是Yahoo返回的数据，未逐笔对照交易所原始记录，不能称为交易所认证价格。

原始行情和衍生CSV继续受现有`.gitignore`忽略，只存本地；没有提交、推送或上传。可访问不等于可以再分发。本次配置、代码、元数据和说明可用于复现流程；换设备需要合法携带同一快照。重新下载可能得到不同版本，不能保证重现本次校验值。

## 数据字典与可用时点

原始JSON可能包含最新报价等不属于研究窗口的附加元数据。除核验代码、货币、资产类型和时区外，不查看或用于设计；最终测试原始响应也留在封存目录。

| CSV字段 | 含义、单位与限制 |
| --- | --- |
| date | 原始日线时间戳转换为America/New_York当地日期；文本YYYY-MM-DD。不是数据发布时间，不能因时间戳在早上就认为当天收盘价早上已知 |
| open / high / low | 供应商日线开盘/最高/最低值，美元/份；按响应保留，未另施调整；所有历史公司行动尚未逐项重建，不用于宣称历史逐笔成交真实性 |
| close | 供应商收盘价，美元/份；Yahoo标注为按拆股调整，不能标成“完全无复权的原始收盘价”，也不是NAV |
| adj_close | 供应商调整后收盘价，美元/份；调整涉及拆股及分红/资本利得分配，不是当时可直接成交的价格 |
| volume | 供应商日成交量，份；非负整数，0不自动视为缺失。历史拆股对其口径的处理未独立核实，使用成交量信号前须再核验 |

Yahoo[历史表格字段说明](https://finance.yahoo.com/quote/SEQ/history/)明确区分Close和Adj Close；只引用其字段说明，不使用该无关标的的价格。Yahoo[调整后收盘价说明](https://help.yahoo.com/kb/SLN28256.html)解释拆股和分配调整。以上2026-11-14核验。不要把课堂A题对虚构close的“无复权”定义直接移植到真实供应商。

缺失的JSON null转换为CSV空白，读取时为None，不填0、不前向填充、不借用NAV。转换保留来源行序和数值，不排序、去重、删日期、重算复权或按表现筛选；重复及非法值仅报告。source JSON保留事件信息，衍生CSV本轮只提取上述七列，不把未提取分红字段解释为没有分红。

日频、美元、纽约日期已检查，历史精确发布延迟及当时修订版本未知。今日下载的复权值可能受后来的公司行动影响，是当前版本历史序列，不是逐日当时可见数据。后续策略要明确价格收益/含分配收益口径、可使用的比例特征和成交时点；不得把绝对复权价当作当时已知报价，亦不能在含分配调整收益上重复加分红。当前不执行任何成交假设。
