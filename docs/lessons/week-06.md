### 来源与假设

核验日期2026-11-01：[SEC Investor.gov：Asset Allocation and Diversification](https://www.investor.gov/introduction-investing/getting-started/asset-allocation)。核验资产配置与期限/风险承受能力的关系、不同资产涨跌导致配置比例变化，以及多只基金可能重叠持仓的边界。以下金额、产品和变动幅度均为教师构造，非真实行情、预测或建议比例。

本课组合边界为单个虚构投资账户内的全部证券市值及留存现金，不把账户外家庭资产并入分母。无杠杆、无负债、无卖空；不追加或取出资金、不交易，无分红派息、税费和现金利息，美元计价，无汇率换算。资产变动仅按题设ETF市场价格变化计算。为专注分类，假设股票ETF只提供股票资产敞口，债券ETF只提供债券资产敞口，暂不穿透基金少量现金或其他持仓；真实产品须查持仓。证券市值不是保证可按同价全部变现的现金。

### 从已学知识连接新概念

上周学习一家公司如何赚钱，本课转向投资者账户。公司资产、利润属于公司层面的概念；投资者持有ETF份额，基金持有股票或债券，不能把基金底层资产再加进投资者账户导致重复计数。

投资组合是把指定范围内的投资和现金作为一个整体观察。资产配置是决定这个整体在股票、债券、现金等资产类别之间如何分配。权重是某一部分当前价值占组合当前总价值的比例；描述每100美元中有多少美元在这一部分。计划分配的目标权重与当下实际权重可能不同。

按底层资产分类时，股票ETF计入股票部分、债券ETF计入债券部分。ETF是基金的交易形式，并不与股票/债券构成互斥的第三种底层资产类别。两只名称不同、都主要持有同类股票的ETF，不因此形成股票加债券的跨类别配置。

资产配置把各部分的涨跌按投入金额传到整个组合，比例不同会改变同一市场情景下的整体结果。比例选择需联系资金何时使用、亏损是否影响必要支出以及心理承受意愿；愿意承受不等于客观承担得起。教学比例不是个人推荐。分散并不保证无亏损，债券ETF价格也可能下跌，本课假设某期不变不等于现实保本。

### 完整示范（虚构）

一个投资账户持有股票ETF60份，每份100美元；债券ETF30份，每份100美元；现金1,000美元。

| 部分 | 当前价值（美元） | 实际权重 |
| --- | ---: | ---: |
| 股票ETF | 60×100=6,000 | 6,000/10,000=60% |
| 债券ETF | 30×100=3,000 | 3,000/10,000=30% |
| 现金 | 1,000 | 1,000/10,000=10% |
| 合计 | 10,000 | 100% |

证券市值=持有份额×当前每份价格。分母是同一时点账户全部证券市值加现金；本例不能除以仅证券的9,000，也不能按60份与30份的数量直接求金额权重。三部分互不重叠且覆盖整个无负债账户，所以权重合计100%。账户有多少资产不等于已全部用于购买证券。

假设接下来一段期间股票ETF价格跌20%，债券ETF价格和现金都不变，且遵守上述无交易等条件：

- 股票ETF每份80美元，持有仍60份，市值4,800美元；债券ETF仍3,000，现金仍1,000。
- 期末总价值=4,800+3,000+1,000=8,800美元。
- 组合盈亏=8,800−10,000=−1,200美元；组合收益率=−1,200/10,000=−12%。
- 也可用期初权重核对：60%×(−20%)+30%×0%+10%×0%=−12%。单期加权收益在本课假设下使用期初权重，不用期末权重回算这一期收益；更一般的现金分配/外部资金流条件另行处理。
- 如果同样10,000全部处在该股票ETF中，本情景损失2,000；本例仅6,000承受这20%的下跌，损失1,200。其余部分此期恰好不变，不代表以后总能抵消。
- 期末股票部分实际权重=4,800/8,800≈54.55%，原目标60%不会自动保持。持有份额未变，但价格及组合总价值改变；当前权重不能沿用期初分母10,000。将实际比例调整回目标涉及再平衡，后续课程讲解。

所有A/B/C资产、收益和资金均为教师虚构，不映射实际股票/债券产品，不推荐比例。下表各行代表三个资产在相同期间的配对收益；四期只是教学构造，不能据此估计真实稳定关系。无借款/杠杆/卖空、税费、分红派息、汇率变动，单期内不交易、不追加或取出资金；价格收益即本题持有收益。期初资金全部分配给两项资产，无另留现金。

### 先解释共同变化的用途与机制

上节已经算出组合收益由期初权重与各部分收益共同决定。现在看多个期间：若持仓经常一起出现较差收益，亏损容易集中出现；若一部分较差时另一部分相对较好，金额变化可能部分抵消。分散效果与资产对共同条件的反应有关，不能只数产品数量。

虚构机制：两家面向同类顾客、主要收入来自同一种产品的企业，若共同需求下降，都可能受影响。只分散企业名称，未必分散共同需求风险；一家企业单独出现问题时，持有其他企业则可能减轻该企业对组合的影响。相关性描述一起变化的统计关系，不证明甲导致乙，也不能仅凭同涨同跌查明具体原因。

本课讲收益率的相关性：比较同一批期间内，两项资产的收益相对各自平均水平如何共同偏离。正相关是较常一起高于各自平均/一起低于各自平均；负相关是较常一项高于自己的平均时另一项低于自己的平均。相关程度较弱表示这种线性共同变化较不明显，不等于没有任何关系。公式、精确系数及统计推断留待第8周。不能把正相关严格定义成每次同涨同跌，也不能把负相关写成一跌另一项必涨。

### 四期配对收益示范

| 观察期间 | A | B | C |
| --- | ---: | ---: | ---: |
| 第1期 | +10% | +8% | −6% |
| 第2期 | −10% | −8% | +6% |
| 第3期 | +6% | +4% | −2% |
| 第4期 | −6% | −4% | +2% |

本例三列四期算术平均恰为0，便于用正负直观看共同变化。A/B呈同向关系；A/C呈反向关系。现实均值未必0，不能只数正负号判相关；例X为1%、2%、3%，Y为−3%、−2%、−1%，两列相对各自平均2%和−2%的偏离均为−1、0、+1个百分点，体现正向共同变化，尽管X每期为正、Y每期为负。此例为教师边界补充，不另加考试要求。

四行只观察单项收益，不假定一个组合连续四期都保持50/50。不将单期示范直接连成固定权重回测；持有不交易会发生上课所学的权重变化。

### 完整单期组合示范

单独取上表第2期，假设这一期期初各方案总额1,000美元，期初各半：P为A500+B500，Q为A500+C500。P/Q是两个独立方案。

- P：A变为500×0.90=450，B变为500×0.92=460；合计910美元，亏90美元，收益率−9%。
- Q：A同样为450，C变为500×1.06=530；合计980美元，亏20美元，收益率−2%。
- Q中A亏50、C赚30，部分抵消，所以亏损较P小，但仍亏20。P中的两项同时损失，名称不同未能在这期形成这种抵消。
- 若另做一个独立单期情景，期初同为1,000各半，采用第1期收益：P为550+540=1,090，收益+9%；Q为550+470=1,020，收益+2%。Q的上行也较小；不能把减轻波动理解为每期赚得更多。
- 再独立设A跌10%、C也跌6%，Q从期初各500变为450+470=920美元，收益−8%。这个新假设说明之前的反向表现不是保本承诺。

这些是各自从期初1,000、各半开始的单期对照，不是把上期余额接到下一期，也不涉及再平衡交易。

### 分散的边界

分散可减轻单一持仓的问题集中作用于全部资金，但不能排除共同冲击。收益关系可能变化，有限历史不足以保证未来；正相关不要求每期同涨同跌，负相关不保证每期反向。较低相关性在其他条件相同时有助于分散，但不是唯一指标，还需看各资产波动幅度和配置权重。例如金额上跌50与涨30无法完全抵消。相关性描述共同变化，不给出谁造成谁变化的因果证据。

### 来源与教学假设

核验日期2026-11-07：[SEC Investor.gov：Asset Allocation and Diversification](https://www.investor.gov/introduction-investing/getting-started/asset-allocation)，Rebalancing部分支持实际配置漂移、恢复配置及按时间或偏离程度再平衡的概念。下列金额、产品、价格和目标比例均为虚构教学情景，不是个人配置建议或真实行情。

本课只计算一个账户内股票ETF市值、债券ETF市值和留存现金，无杠杆、负债或卖空。无外部追加/取出资金、分红、利息、费用、税费、买卖价差、滑点和汇率变化。假设调仓全程价格不变、全部按题设价格成交；只核算相关交易全部完成并结算后的持仓与现金，不研究结算等待或资金可用权限。所有示范和A题交易均为整数份，无需假定真实券商支持零股份额。现实执行条件和成本另行核验，不能套用本题为真实成交保证。

### 解释、完整示范与边界

复习：份额不变，价格变化也会使权重变化；分散不保证保本。目标权重是计划分配的比例，实际权重是当前各部分价值除以当前账户总价值。再平衡是在目标仍适用的前提下，调整持仓使实际比例回到目标。它管理组合承担的风险构成；将原目标改成新目标还涉及配置计划的改变。

沿用W06D01的示范账户作为独立新情景：起初股票ETF60份×100美元=6,000，债券ETF30份×100美元=3,000，现金1,000，总额10,000；目标60%/30%/10%。随后股票ETF涨至150美元，债券ETF仍100美元，现金不变。投资者仍持有ETF份额，基金底层股票或债券不重复加入账户总额。

当前股票9,000、债券3,000、现金1,000，总额13,000美元；实际权重约69.23%/23.08%/7.69%。股票上涨使其对组合今后涨跌的影响比原计划更大。假如接下来仅股票跌10%，不调仓时股票造成900美元损失；调回目标后同样假设会造成780美元损失。若仅股票涨10%，两种方案的股票盈利也分别是900和780，不能由此保证再平衡收益更高。这是教师给定的独立未来情景示范，不是预测，也非用户作答证据。

先用当前13,000计算目标金额，再计算差额：

| 部分 | 调仓前金额（美元） | 目标权重 | 目标金额（美元） | 目标减当前（美元） |
| --- | ---: | ---: | ---: | ---: |
| 股票ETF | 9,000 | 60% | 7,800 | −1,200 |
| 债券ETF | 3,000 | 30% | 3,900 | +900 |
| 现金 | 1,000 | 10% | 1,300 | +300 |

目标金额=当前总价值×目标权重。证券调整金额=目标金额−当前市值，正数买入、负数卖出；买卖份额=调整金额的绝对值÷当前每份成交价格。现金目标通过证券买卖后的余额实现，不能把现金增加再当作一笔证券买入。

卖股票ETF1,200÷150=8份，持有剩52份；买债券ETF900÷100=9份，持有变39份。现金路径为1,000+1,200−900=1,300。卖出的1,200美元中900用于买债券ETF，300留为现金。卖出回款只是证券转换为现金，不能再把它整体当作新利润。

交易后核对：股票52×150=7,800，债券39×100=3,900，现金1,300，总额仍13,000；权重60%/30%/10%。按当前总价值分配，所以不是退回最初10,000美元和原份额；此前价格上涨已经创造了3,000账面增值，这次无成本换仓本身没有创造新增价值。

再平衡不等于判断股票明天会跌。未来股票若继续上涨，卖掉一部分可能使组合比不调仓少赚；资产共同下跌时，恢复比例后仍可能亏损。现实交易还要考虑成本，不能把本例总价值不变推广到含成本交易。常见规则是按预定日期检查，或在比例偏离预设范围时处理；本课不选择个人执行频率。也可用新增投入补充低于目标的部分，但会改变总额，本课先采用无外部资金流条件。

本课调用：

```python
result = rebalance(
    stock_shares=80, bond_shares=40,
    stock_price=100, bond_price=100,
    cash=3000, stock_weight=0.50, bond_weight=0.40,
)
```

输入是当前两只ETF的份额、每份价格、现金余额和题设目标权重；现金目标为剩余10%。程序不会自行选择比例或预测收益。内部先计算股票和债券市值、当前总价值，再按目标与当前金额的差额计算交易：

```python
stock_value = stock_shares * stock_price
bond_value = bond_shares * bond_price
total_before = stock_value + bond_value + cash

stock_trade = total_before * stock_weight - stock_value
bond_trade = total_before * bond_weight - bond_value
stock_shares_after = stock_shares + stock_trade / stock_price
bond_shares_after = bond_shares + bond_trade / bond_price
cash_after = cash - stock_trade - bond_trade
```

`stock_trade`与`bond_trade`单位是美元，正数表示买入，负数表示卖出；`*_shares_after`为交易后份数。用同一符号约定同时更新证券份额和现金，最后重新合计持仓市值与现金、计算权重。讲解这些输入和规则不代表用户已经掌握，需通过下面的解释题确认。

### 追涨：从害怕错过到把过去涨幅当未来保证

“追涨”日常可泛指价格上涨后买入。本课关注的问题是：仅因为最近上涨或别人赚钱，就认为以后必涨，未经评估便投入或改变计划。FOMO即害怕错过，机制示范为：看见他人盈利→觉得自己错失机会→急于赶上→跳过原本的研究和风险检查。未买入期间的上涨不是账户实际损失；后来买入也不会自动取得之前的涨幅。

虚构人物小林观察普通股票ETF X，单价从100涨到120美元；他此前没有持有，只因“大家都赚了，不买就亏了，肯定还会涨”买10份，支出1,200美元，未核对持仓风险或投资计划。若之后跌到90，持仓为900，亏300；若另设之后涨到132，则持仓为1,320，赚120。两种后续都是假设：前者不证明未来必跌，后者也不使“之前上涨所以以后必涨”的推理变成保证。

有明确依据、预先规则及风险评估的上涨后买入，不能仅凭买入时机就判为情绪追涨；后续会研究的趋势/动量规则也需要独立检验。此次只识别小林已明确说出的理由，不评价他的人格或真实心理状况。

### 厌恶损失：账面损失与不愿接受损失

“损失厌恶”（本计划称厌恶损失）指对同等金额的损失，负面感受往往强于获得同额收益的愉悦，是心理倾向，不是人人相同的倍数，也不等同于合理避险。它可能使人为了避免承认亏损，过度依赖原买入价或拒绝检查继续持有的理由；单凭亏损后继续持有不能判定此倾向。

沿用小林实际以120美元买10份的示范，当前单价90，其他条件不变，仅比较此时持有与立即全卖两个分支，不假定下一期价格：

| 当前处理 | ETF份额 | ETF市值 | 现金 | 总价值 | 相对投入1,200的盈亏 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 继续持有 | 10 | 900 | 0 | 900 | −300（未实现） |
| 按90全部卖出并结算 | 0 | 0 | 900 | 900 | −300（已实现） |

未实现亏损指持仓尚未出售时，相对成本的市值损失；卖出后成为已实现亏损。在本题固定价格、无成本条件下，卖出将900美元证券换成900美元现金，没有在卖出瞬间额外损失300。持有期间市值损失已存在，也可能随后扩大或缩小。

小林若说“只要不卖就没亏，我不看其他条件，必须等回120”，应区分：希望回本是一种愿望；买入价120是计算盈亏的参照，不能证明未来必回120。仅凭这些数据，教师也无法判定现在一定该卖或该留。继续持有应重新考察当前证据、资金用途和期限、承担的风险及原计划是否适用。真实税费和交易约束另行分析，不从本例推导现实所有买卖均无影响。
