### 来源与假设

核验日期2026-11-01：[SEC Investor.gov：Asset Allocation and Diversification](https://www.investor.gov/introduction-investing/getting-started/asset-allocation)。核验资产配置与期限/风险承受能力的关系、不同资产涨跌导致配置比例变化，以及多只基金可能重叠持仓的边界。以下金额、产品和变动幅度均为教师构造，非真实行情、预测或建议比例。

本课组合边界为单个虚构投资账户内的全部证券市值及留存现金，不把账户外家庭资产并入分母。无杠杆、无负债、无卖空；不追加或取出资金、不交易，无分红派息、税费和现金利息，美元计价，无汇率换算。资产变动仅按题设ETF市场价格变化计算。为专注分类，假设股票ETF只提供股票资产敞口，债券ETF只提供债券资产敞口，暂不穿透基金少量现金或其他持仓；真实产品须查持仓。证券市值不是保证可按同价全部变现的现金。

### 从已学知识连接新概念

上周学习一家公司如何赚钱，本课转向投资者账户。公司资产、利润属于公司层面的概念；投资者持有ETF份额，基金持有股票或债券，不能把基金底层资产再加进投资者账户导致重复计数。

投资组合是把指定范围内的投资和现金作为一个整体观察。资产配置是决定这个整体在股票、债券、现金等资产类别之间如何分配。权重是某一部分当前价值占组合当前总价值的比例；描述每100美元中有多少美元在这一部分。计划分配的目标权重与当下实际权重可能不同。

按底层资产分类时，股票ETF计入股票部分、债券ETF计入债券部分。ETF是基金的交易形式，并不与股票/债券构成互斥的第三种底层资产类别。两只名称不同、都主要持有同类股票的ETF，不因此形成股票加债券的跨类别配置。

资产配置把各部分的涨跌按投入金额传到整个组合，比例不同会改变同一市场情景下的整体结果。比例选择需联系资金何时使用、亏损是否影响必要支出以及心理承受意愿；愿意承受不等于客观承担得起。教学比例不是个人推荐。分散并不保证无亏损，债券ETF价格也可能下跌，本课假设某期不变不等于现实保本。

### 完整示范（虚构）

一个投资账户持有股票ETF60份，每份100美元；债券ETF30份，每份100美元；现金1,000美元。

| 部分 | 当前价值（美元） | 实际权重 |
| --- | ---: | ---: |
| 股票ETF | 60×100=6,000 | 6,000/10,000=60% |
| 债券ETF | 30×100=3,000 | 3,000/10,000=30% |
| 现金 | 1,000 | 1,000/10,000=10% |
| 合计 | 10,000 | 100% |

证券市值=持有份额×当前每份价格。分母是同一时点账户全部证券市值加现金；本例不能除以仅证券的9,000，也不能按60份与30份的数量直接求金额权重。三部分互不重叠且覆盖整个无负债账户，所以权重合计100%。账户有多少资产不等于已全部用于购买证券。

假设接下来一段期间股票ETF价格跌20%，债券ETF价格和现金都不变，且遵守上述无交易等条件：

- 股票ETF每份80美元，持有仍60份，市值4,800美元；债券ETF仍3,000，现金仍1,000。
- 期末总价值=4,800+3,000+1,000=8,800美元。
- 组合盈亏=8,800−10,000=−1,200美元；组合收益率=−1,200/10,000=−12%。
- 也可用期初权重核对：60%×(−20%)+30%×0%+10%×0%=−12%。单期加权收益在本课假设下使用期初权重，不用期末权重回算这一期收益；更一般的现金分配/外部资金流条件另行处理。
- 如果同样10,000全部处在该股票ETF中，本情景损失2,000；本例仅6,000承受这20%的下跌，损失1,200。其余部分此期恰好不变，不代表以后总能抵消。
- 期末股票部分实际权重=4,800/8,800≈54.55%，原目标60%不会自动保持。持有份额未变，但价格及组合总价值改变；当前权重不能沿用期初分母10,000。将实际比例调整回目标涉及再平衡，后续课程讲解。

所有A/B/C资产、收益和资金均为教师虚构，不映射实际股票/债券产品，不推荐比例。下表各行代表三个资产在相同期间的配对收益；四期只是教学构造，不能据此估计真实稳定关系。无借款/杠杆/卖空、税费、分红派息、汇率变动，单期内不交易、不追加或取出资金；价格收益即本题持有收益。期初资金全部分配给两项资产，无另留现金。

### 先解释共同变化的用途与机制

上节已经算出组合收益由期初权重与各部分收益共同决定。现在看多个期间：若持仓经常一起出现较差收益，亏损容易集中出现；若一部分较差时另一部分相对较好，金额变化可能部分抵消。分散效果与资产对共同条件的反应有关，不能只数产品数量。

虚构机制：两家面向同类顾客、主要收入来自同一种产品的企业，若共同需求下降，都可能受影响。只分散企业名称，未必分散共同需求风险；一家企业单独出现问题时，持有其他企业则可能减轻该企业对组合的影响。相关性描述一起变化的统计关系，不证明甲导致乙，也不能仅凭同涨同跌查明具体原因。

本课讲收益率的相关性：比较同一批期间内，两项资产的收益相对各自平均水平如何共同偏离。正相关是较常一起高于各自平均/一起低于各自平均；负相关是较常一项高于自己的平均时另一项低于自己的平均。相关程度较弱表示这种线性共同变化较不明显，不等于没有任何关系。公式、精确系数及统计推断留待第8周。不能把正相关严格定义成每次同涨同跌，也不能把负相关写成一跌另一项必涨。

### 四期配对收益示范

| 观察期间 | A | B | C |
| --- | ---: | ---: | ---: |
| 第1期 | +10% | +8% | −6% |
| 第2期 | −10% | −8% | +6% |
| 第3期 | +6% | +4% | −2% |
| 第4期 | −6% | −4% | +2% |

本例三列四期算术平均恰为0，便于用正负直观看共同变化。A/B呈同向关系；A/C呈反向关系。现实均值未必0，不能只数正负号判相关；例X为1%、2%、3%，Y为−3%、−2%、−1%，两列相对各自平均2%和−2%的偏离均为−1、0、+1个百分点，体现正向共同变化，尽管X每期为正、Y每期为负。此例为教师边界补充，不另加考试要求。

四行只观察单项收益，不假定一个组合连续四期都保持50/50。不将单期示范直接连成固定权重回测；持有不交易会发生上课所学的权重变化。

### 完整单期组合示范

单独取上表第2期，假设这一期期初各方案总额1,000美元，期初各半：P为A500+B500，Q为A500+C500。P/Q是两个独立方案。

- P：A变为500×0.90=450，B变为500×0.92=460；合计910美元，亏90美元，收益率−9%。
- Q：A同样为450，C变为500×1.06=530；合计980美元，亏20美元，收益率−2%。
- Q中A亏50、C赚30，部分抵消，所以亏损较P小，但仍亏20。P中的两项同时损失，名称不同未能在这期形成这种抵消。
- 若另做一个独立单期情景，期初同为1,000各半，采用第1期收益：P为550+540=1,090，收益+9%；Q为550+470=1,020，收益+2%。Q的上行也较小；不能把减轻波动理解为每期赚得更多。
- 再独立设A跌10%、C也跌6%，Q从期初各500变为450+470=920美元，收益−8%。这个新假设说明之前的反向表现不是保本承诺。

这些是各自从期初1,000、各半开始的单期对照，不是把上期余额接到下一期，也不涉及再平衡交易。

### 分散的边界

分散可减轻单一持仓的问题集中作用于全部资金，但不能排除共同冲击。收益关系可能变化，有限历史不足以保证未来；正相关不要求每期同涨同跌，负相关不保证每期反向。较低相关性在其他条件相同时有助于分散，但不是唯一指标，还需看各资产波动幅度和配置权重。例如金额上跌50与涨30无法完全抵消。相关性描述共同变化，不给出谁造成谁变化的因果证据。
