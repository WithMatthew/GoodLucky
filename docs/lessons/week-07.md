### A组前的讲解与完整示范

前6周已学会用价格计算持仓市值、收益和回撤。从本课开始，要先知道价格从哪来、记录的是什么、当时能否获知，再把数据交给程序。

**日频数据**：以一个交易日为单位整理数据。在今天的简化表里，一行描述一只ETF在一个交易日内的行情，一列代表一个字段。“字段”就是一项有明确含义的数据，例如收盘价。休市日并不自然产生一条真实成交记录，日期不能直接当成连续自然日。

本课全部数字由教师虚构，ETF名称“教学ETF”不是真实交易代码。只统计假定常规交易时段内、纳入本例统计范围的成交，价格单位为美元/份，成交量单位为份；没有分红、拆股、费用、买卖或资金进出。D0和D1是相邻交易日的占位标签，不是下载日期。真实文件须写明交易当地日期、时区、交易时段、市场覆盖、来源和获取时间。

| 字段 | 中文 | 本例的定义与单位 |
| --- | --- | --- |
| date | 交易日期 | 该行所属的交易当地日期，本例暂用D0/D1占位 |
| open | 开盘价 | 本例统计时段内第一笔成交的价格，美元/份 |
| high | 最高价 | 本例统计时段内成交价格的最大值，美元/份 |
| low | 最低价 | 本例统计时段内成交价格的最小值，美元/份 |
| close | 收盘价 | 本例统计时段内最后一笔成交的价格，美元/份 |
| volume | 成交量 | 本例统计范围内成交份数的累计值，份 |

后五个字段常缩写为OHLCV。真实数据的开收盘价可能采用官方开收盘价格或符合提供商规则的成交价，必须查对应说明；不能把本例“第一笔/最后一笔”的简化规则用于所有来源。Alpha Vantage官方日频接口文档列出了日期和OHLCV，并把原始成交价格与调整后的数据区分开；本课引用它核对字段体系，不代表已选它作为数据源。

**成交量是交易活动，个人持仓是你拥有的数量。**一次买方接过100份、卖方交出100份，按本例单边成交口径记100份，不把买卖双方加成200份。同一批份额在一天中反复转手会反复计入成交量。因此，成交量不是你的份数、基金总份额或成交金额。ETF行情价格描述的是基金份额的交易价格，不是把底层全部股票的价格相加。

完整例子：D0收盘100美元/份；D1记录如下。

| date | open | high | low | close | volume |
| --- | ---: | ---: | ---: | ---: | ---: |
| D1 | 100 | 105 | 98 | 102 | 1,000 |

这表示本例D1开盘100，成交价最高105、最低98，收盘102；全天累计成交1,000份。它不表示个人账户有1,000份，也不表示全天每一笔都按102成交。

若你从D0收盘到D1收盘一直持有10份，D1收盘的持仓市值是`10 × 102 = 1,020美元`。这段收盘到收盘的价格收益率是`(102 − 100) / 100 = 2%`；持仓市值比D0收盘增加20美元。例中没有分红、费用或资金进出，才可直接这样比较；账户若另有现金或其他持仓，还需一并纳入账户总价值。这里的分母是指定起点D0的收盘价，不是随意选一个当天价格。

同一行可以来自`100 → 98 → 105 → 102`，也可以来自`100 → 105 → 98 → 102`。两条路径开盘、最高、最低和收盘完全相同；仅凭这一行，无法确定先到最高价还是先到最低价，也无法知道每个价位能成交多少份。全天成交量乘收盘价也不等于精确成交金额，因为成交可能发生在不同价格。

在D1刚开盘时，D1最终的最高、最低、收盘和全天成交量尚未形成。**完整日频行须等该统计时段结束，且数据实际发布、被取得后，才能供当时的决策使用。**之后下载的历史表虽然已经填全，不能倒过来假装当天开盘时就知道；这类使用当时尚不可得的信息的错误称为“前视偏差”。盘中显示的数值可能只是截至当时的临时统计。

将字段的含义、单位和约定写成说明表，叫作**数据字典**。对整个数据集补充来源、获取时间、时区、统计时段、价格是否调整等背景说明，便于判断能否使用；这部分也常称为元数据。本课数据说明：教师虚构，编写于2026-11-08；单只教学ETF；D0/D1相邻交易日；假定美国东部交易当地日期及常规时段；美元/份、成交量份；使用本例未调整的成交价格、无公司行动；未从行情提供商下载，缺失值规则尚未进入实践。真实下载时间不得以本课编写日期代替。

### B组前：CSV读取、类型转换与完整示范

CSV是逗号分隔的文本文件。本例首行保存字段名，后面每行保存一天的数据。它没有自动理解价格或日期的能力；读入时要由程序明确解释。

新增文件：`data/synthetic/daily_demo.csv`。全部数据仍为虚构；D1沿用A题，D0的close=50沿用已知条件，其余D0字段由教师补齐用于演示完整文件结构，并非从市场取得。数据字典与来源、单位、时区和边界保存在同目录README。

```csv
date,open,high,low,close,volume
D0,50,51,49,50,12000
D1,51,54,49,52,20000
```

CSV中的成交量写`20000`，不加展示用的千位逗号，否则未经引号保护的逗号会被当成分隔符。D0/D1继续作为交易日占位文本；真实日期解析下一课再讲。

Python标准库`csv.DictReader`按首行字段名，把每条数据读成一个字典，例如第二条数据中有`{"date": "D1", "close": "52", "volume": "20000", ...}`。默认读到的值是字符串，`list(...)`把这些行收集成列表。首行字段名不算数据行，因此列表长度为2；Python从0计数，`rows[0]`为D0、`rows[1]`为D1。

完整示范如下，在仓库根目录运行时，路径指向已保存的教学CSV：

```python
import csv
from pathlib import Path

path = Path("data/synthetic/daily_demo.csv")
with path.open(encoding="utf-8", newline="") as f:
    rows = list(csv.DictReader(f))

previous_close = float(rows[0]["close"])
current_close = float(rows[1]["close"])
volume = int(rows[1]["volume"])
shares = 20

price_return = (current_close - previous_close) / previous_close
market_value = current_close * shares

print(f"price_return={price_return:.2%}")
print(f"market_value={market_value:.2f} USD")
```

逐步理解：

1. `path.open(...)`打开文本文件。`encoding="utf-8"`指定编码，`newline=""`让CSV模块处理换行；`with`保证读完关闭文件。
2. `csv.DictReader(f)`读取首行作为键名；`rows[1]["close"]`依次选第二条数据、其中的close字段，此时得到字符串`"52"`。
3. `float("52")`得到数值`52.0`，适合带小数的价格；`int("20000")`得到整数`20000`。本例成交量约定为整数份数，不能把这个转换规则直接套到所有数据源和资产。
4. 字符串直接相加会拼接，如`"50" + "52"`得到`"5052"`；字符串之间直接相减会报错。先明确转换，才能执行这里的数值运算。
5. `shares=20`是独立给定的个人持仓；程序使用收盘价格计算收益和市值，读取的volume不参与这两个公式。
6. `:.2%`把比例显示成两位小数的百分比，`:.2f`显示两位小数；这是输出格式，不改变原始数据。没有改变CSV，也没有执行交易。

仓库可运行版本为`src/read_daily.py`。它将读取封装为`read_daily_rows(path)`，仍保持字符串字段及原文件顺序；主程序用脚本所在位置定位仓库，避免本机绝对路径。导入模块不自动读取文件或运行示例。

### A组前：一个贯穿的完整示范

复习：上课确认了日期、缺失和重复都要检查，但即使数据完整正确，直接比较两个收盘价也不总能代表持有人的盈亏：期间可能发生拆股或现金分红。以下全部数字和时间顺序由教师构造，不是真实行情，也不是SPY历史事件。

统一假设：虚构“小树公司”的同一类普通股，无税费、汇率变化、买卖、外部资金进出、现金利息或分红再投资。投资者全程持有并确定有本次分红资格；公司如约付款，不考虑应收款折现或信用损失。涉及拆股或分红的机械价格变化时，先排除其他市场/经营信息；现实成交价格仍由市场交易形成，不保证严格等于参考值。单价单位美元/股，数量单位股，金额单位美元。

**拆股：每股代表的权益份量改变，持股比例不因此改变。**“1拆2”指每1股旧股变为2股新股。假设公司原来共1,000股，你持有10股，每股100美元；公司同类全部股份同比例拆分，公司业务、资产、负债及整体估值不因单纯拆股变化，没有外部投资者投入新资金。这与仅向别人增发新股不同。拆后公司2,000股，你20股，每股机械参考价50美元。

| 项目 | 拆股前 | 1拆2后（仅机械变化） |
| --- | ---: | ---: |
| 公司总股数 | 1,000股 | 2,000股 |
| 你的股数 | 10股 | 20股 |
| 你的持股比例 | 10/1,000=1% | 20/2,000=1% |
| 每股价格 | 100美元 | 50美元 |
| 你的持仓市值 | 10×100=1,000美元 | 20×50=1,000美元 |

每股原来代表公司的1/1,000，拆后每股代表1/2,000，因此不能只比较100与50便认定持有人损失50%。股数翻倍也不表示财富翻倍。数据表中的100和50都可以是正确原始价格，错误发生在把不同单位份量当成可直接比较的一股。现实期间其他因素仍可能引起价值变化，本例只隔离拆股本身。

**现金分红：持股数量不变，一部分价值转成了持有人另收的现金。**接着使用拆股后的20股、每股50美元。公司决定按拆股后每股派2美元，你有权收20×2=40美元。假设其他因素不变，分红后的机械参考价为50−2=48美元；持股数仍20股，因为没有再投资。公司用于这次支付的现金最终离开公司，股东保有的股票所代表权益与已分离的收款权利需要分别看，不能把50美元旧价格和新收2美元同时当作都未改变的资产。

等40美元已经到账、且没有再发生价格变化时：

- 股票市值：20×48=960美元。
- 另持分红现金：40美元。
- 合计：960+40=1,000美元。
- 以分红前持仓1,000美元为起点，总收益率：(960+40−1,000)/1,000=0。

只看股价50到48，会算出−4%的价格变化；在本例中，它没有包含另收现金，因此不等于持有人的总收益。分红按现金方式领取不会自动增加持股数量；若选择再投资，份数变化还需另记，今天假设不再投资。

现实股价不保证正好从50到48。独立观察变式：若派2美元后观察价为49，你的20股市值980加40现金合计1,020美元，相对分红前1,000美元的总收益率为2%；这个额外变化不能只归因于派息本身。本例金额由教师示范，不计为用户手算。

ETF也会向份额持有人作现金分配，常被简称为“分红”；基金分配可来自股息、利息、已实现收益等，不能把所有分配都等同于公司股息。本课只看现金如何从基金内部转到持有人：其他条件不变时，分配会减少基金NAV；市场成交价与NAV仍须区分。上节SPY来源只有NAV，不含完整分红账本，不能仅凭NAV下跌判定同额投资损失，也不能据此假定真实样本没有分配。

**除息与到账是两个环节。**就本课普通现金分红的简化情形，除息表示股票交易不再附带本次分红资格；发放日是发行人实际支付款项的日期，账户入账以实际处理为准，不应把两者混为一日。本课已给定你有资格，全程持有，不要求推算登记日、结算日或特殊分红规则。

仍用上面40美元：在已除息、尚未付款时，你另有40美元应收分红（有权收到但尚未到账的款项），不是40美元可用现金。按题设必定付款且不计折现，持仓960+应收40=1,000美元；到账后变为持仓960+现金40=1,000美元，应收归零。到账是应收转成现金，不能把同一笔款项再次记作新增40美元收益。这里把应收纳入教学资产合计，不表示券商页面必按相同方式显示，更不表示它已经可交易或提现。

### B组前：复权与总收益的完整示范

复权是按拆股、分红等事件的规则调整价格序列，使比较符合明确的口径。原始记录仍保留：调整不是认定旧记录错了，也不会改写当年的交易。下面沿用小树公司示范；全部为虚构教学数据，不是SPY事件。

**先看只有拆股的情形。**沿用1拆2之前100美元、之后50美元；再增加下一交易日收盘55美元的市场变化，三日之间没有分红。把拆股前每股价格除以2，相当于换算为“拆后1股所代表的份量”，拆股当天及之后保持原值：

| 时点 | 原始收盘价（美元/当时1股） | 拆股复权序列（美元/拆后1股等价份量） |
| --- | ---: | ---: |
| 拆股前一天 | 100 | 50 |
| 拆股当天 | 50 | 50 |
| 后一交易日 | 55 | 55 |

原始100→50直接相比为−50%，跨了每股份量变化，不能据此说持有人亏一半。调整后50→50为0%；随后50→55为10%。以本例保留拆后价格、改算此前价格的方式，历史调整系数为1/2，常称为拆股复权因子；本课不要求背不同供应商的模式名称。

100与50并不矛盾：前者记录当时完整旧股的收盘价，后者是每半股旧股、即1股新股份量的可比数值。查询当年的真实收盘记录仍用100；不能声称当年按50就能买1整股旧股。要核对历史市值，也应把当时真实股数和当时原始价格配对，不能拿10股旧股乘以调整后的50。具体模拟成交还须另外规定成交时点、价差/滑点等，原始收盘价也不保证个人当时一定能成交。

**再看现金分红。**拆股调整只解决每股份量变化；现金分红没有增加你的股数，需要另把分红算入收益。沿用A示范中的独立变式：你有20股，分红前每股50；每股派2，期末市场价49，分红已经到账并留作现金，无新拆股、税费或其他现金流。这里允许市场价变化，区别于A练习的纯机械价格假设。

- 原始价格变化率：(49−50)/50=−2%。
- 持仓980+分红40=1,020，期初1,000，总收益率2%。
- 同一计算缩到1股：(49+2−50)/50=2%。

后一公式只用于本期股数口径已一致、持有并有分红资格的这个单期情形。分子既算股票价值变化，也算分红；金额由20股缩为1股，分母同样缩为1股期初价格，因此比率不变。若未付款，按此前确定付款且不折现的假设用应收代替现金，不能将两者同时加上。

为了把总收益画成一条线，可自行定义“总收益参考序列”：起点设为100点，每期乘以1+该期总收益率。本期就是100×(1+2%)=102点；102/100−1=2%。100和102是参考点位，不是每股美元报价，起点100是人为选择，换成1,000→1,020不会改变比例。它将本期分红影响已经计入；再加2/50=4%会把同一笔分红算两次。原始49配合另记现金的账本，与含分红参考序列，是两种记录角度。

本例是按上述定义构造的一期教学序列，不能冒充任何平台adj_close的通用算法。实际数据存在仅调整拆股、同时处理分红等不同模式；字段名“复权价/adjusted close”本身不足以说明全部算法。应查供应商说明的调整范围、基准和计算方式；涉及跨期分红时还要核对是否假设再投资。再投资指用分红买入更多股票，这些新增股份会参加后续涨跌；现金留存则持股数不增加，所以多期结果可能不同。

本课先掌握两个用途：真实账户的市值与现金账本需要原始价格、实际持股数量和现金/应收；收益比较可使用定义适合目标的调整后序列，但已经包含的分红不能再加。既有SPY样本是NAV，仅有这一列不能自动补出总收益序列或完整分红账本。

资料边界：QuantConnect官方文档区分调整模式，Alpha Vantage文档分别列出原始OHLCV、调整收盘价及拆股/分红事件；本课只引用这些字段与口径区分，不调用其接口、不创建账户、不将其收费/API要求引入原免费样本练习。教学参考序列公式由本课显式定义并手算，不是对任何供应商精确算法的断言。

**NAV与Close：同一份ETF的两个角度。**本课nav列指每份基金净资产价值，即per-share NAV；NAV在严格表述中也可指基金总净资产，读文件要确认是否已经除以份额。

每份NAV=(基金全部资产按估值规则计算的价值−负债)/流通基金份额。资产包含持有的证券、现金、应收款等，扣除应付费用等负债。它反映这一份对应多少基金净资产，既不是最初投入成本，也不是保证能卖出的价格。虚构基金证券9,500美元、现金600、负债100，发行1,000份：总净资产=9,500+600−100=10,000，每份NAV=10美元。

同一ETF的原始Close是规定交易时段、市场及数据规则下的收盘价格，反映市场上ETF份额怎样成交。它不是基金把资产加总算出的数字。日频Close通常用于常规时段收盘，但实际读取必须核对来源的市场、交易时段和是否已调整；不能将盘后末价、收盘拍卖价或买卖报价中点混为同一字段。

假设上面ETF当天Close为10.10美元，NAV为10美元。买方愿付10.10且卖方同意，交易即可发生；在普通投资者之间转手时，款项付给卖方，基金并不因此额外收到这笔购买款，基金持仓和总份额也不会仅因转手自动改变。因此基金每份净资产可以仍是10美元。价格高于NAV叫溢价，低于NAV叫折价；这里(10.10−10)/10=1%溢价。NAV没有变也不代表交易者没有盈亏：以10.10买、后来以10卖，在无分红费用假设下每份仍亏0.10美元。

底层资产的价格影响NAV，ETF份额的供求、流动性和当时市场报价也影响Close；两者是相连的估值/交易过程，不能理解成一个永远真实、另一个必定错误。比较时还应对齐估值日期和时间，旧NAV不自动代表当前可交易的底层价值。

二者通常接近还与申购赎回机制有关。授权参与者（能按规则与基金成批交换资产和ETF份额的机构）可交付规定资产篮子取得ETF份额，也可反向交回ETF份额换取篮子。忽略成本的示范中，若取得篮子的成本折合每份约10、ETF市场价10.10，机构可买篮子换ETF再卖出，增加ETF供给，倾向缩小价差；折价时可反向处理。实际存在成本、时点和流动性约束，不保证始终相等；本例每份数字只是大额机制的缩写，不表示零售投资者可直接按NAV申赎1份。

**点数：把已定义的投资表现换成一个共同刻度。**单只股票通常用美元/股报价，本课点数是为跟踪投资表现另行构造的参考序列。NAV/Close是输入或估值数据；点数是先确定追踪对象和收益口径之后的显示方式。点数本身没有“必然含分红”的属性，要先说明是价格表现还是总收益。

构造顺序：先确定追踪哪笔投资、是否计分红及如何处理现金，再选基期（从哪个日期开始比较），为该起点指定一个正的基准点位B，例如100或1000。起点是设定的，后续是按数据算出来的；不能每天任意改起点，也不能中途把100直接换成1000制造十倍增长。若更换显示刻度，整段历史须同比例换算。

无外部资金存入/取出、负债及费用忽略，分红保留在账户，已按实际拆股更新数量时：

    V_t = 当期实际股数 × 当期原始市场价 + 现金 + 应收分红
    I_t = B × V_t / V_0

V_0为基期投资总资产，V_t为当前总资产，I_t为当前点位。现金和应收不能重复计算同一笔分红；若账户有负债需要扣除，若有额外出入金则不能直接照套总资产比值。此处固定无出入金，不引入复杂现金流收益算法。

完整示范沿用B2数字、放大到10股：期初10股×40=400美元；期末10股×39加分红10×2=410美元。实际增长410/400=1.025，与显示刻度无关。

| 时点 | 投资总资产 | 基准100点 | 基准1000点 |
| --- | ---: | ---: | ---: |
| 期初 | 400美元 | 100 | 1000 |
| 期末 | 410美元 | 102.5 | 1025 |

基准100：100×410/400=102.5；基准1000：1000×410/400=1025。两个版本收益都是2.5%。基准1000时上涨25点表示2.5%，不是25%；“点”与“百分比”不同。统一起点和收益口径后，便于比较不同本金、不同单位价格的投资表现，不代表可按点数成交，也不能拿不同基准的绝对点位比较谁更赚钱。

原先递推公式来自同一关系。无出入金且收益口径一致时，本期收益r_t=V_t/V_(t−1)−1，因此I_t=I_(t−1)×(1+r_t)。先把持仓与现金的收益算对，再更新点位；单期含分红公式不能未经说明直接套到所有再投资/现金留存路径。

**拆股前1000点：对本课收益参考序列，纯拆股后仍1000点。**另作独立情景：期初10股、每股40美元，总资产400，设1000点；不分红、无其他变化，只进行1拆4：

| 项目 | 拆前 | 纯拆股后 |
| --- | ---: | ---: |
| 实际股数 | 10 | 40 |
| 原始每股价格（美元） | 40 | 10 |
| 总资产（美元） | 400 | 400 |
| 收益参考点位 | 1000 | 1000 |

拆后I=1000×(40×10)/400=1000，或者r=0所以I=1000×(1+0)=1000。需要除以4的是机械每股价格；数量同时乘4，不能把用于追踪整体表现的点位也除4。若之后市场价真实从10涨到11，则40×11=440，I=1000×440/400=1100，这10%才来自价值变化。

与复权的衔接：按拆后份量调整时，把过去每股40换算为10；比较复权价10→10仍为0%。这与把点位1000除以4不同。跨拆股直接用原始Close 10/40得出−75%，会漏记增加的股数；这样的序列不能代表本课定义的持有收益。点数不自动修正错误输入，正确处理事件才使它保持连续。

正式指数也按各自方法处理拆股，不能统一把指数点位除以倍数。市值加权指数中股数与股价反向变化、市场价值不因纯拆股变化；价格加权指数则需要相应调整除数。实际市场若同时上涨/下跌，点位可变，不把“纯拆股不改变点位”解释为拆股日行情必定不动。
