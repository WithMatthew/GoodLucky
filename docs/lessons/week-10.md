## W10D01　三日均线怎样产生交易信号

第 9 周的买入持有基准在建仓后保留原来的份数。今天给同一个账户加一条规则，让它在每个交易日收盘后，根据最近的价格决定下一步想持有几份 ETF。两种做法都要逐笔记录实际持有的份数和手里的现金。

**三日简单移动平均**（简称三日均线）取截至当天最近三个交易日的收盘价，相加后除以 3。三天的价格各占三分之一，结果和收盘价的单位相同，都是美元/份。每过一个交易日，最早的一天移出，新的一天加入。这样就有了衡量今天价格相对近期水平是高还是低的参照。核验日期为 2026-11-19。[Fidelity 学习中心关于简单移动平均的说明](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/sma)

### 本课的教学规则

用一只虚构 ETF，账户从 100 美元现金、0 份开始，各日均为连续交易日。为集中看清资金和份数如何变化，设费用、税费、现金利息为零，期间无分红、拆股或出入金。

- 前两天只有一两个收盘价，先等凑齐三个。以后每天收盘并取得当天收盘价后，比较收盘价和三日均线。
- 收盘价高于均线，目标为 1 份。等于或低于均线，目标为 0 份。这里的**信号**给出想持有的总份数。这个趋势跟随规则尝试在价格相对近期偏强时持有，价格随后也可能反转。
- 将目标份数与实际持有份数比较。缺 1 份才买 1 份，多 1 份就卖 1 份，相同则维持。需要交易时，在收盘后提交模拟订单，约定按下一交易日开盘价全部成交，届时才更新现金和实际持仓。三天、每次最多持有一份以及成交方式都是本例预先写定的条件。

| --- | --- | --- |
| 第 1、2 天各自收盘后 | 收盘价依次为 48、51。三日均线还算不出，等待。 | 0 份，100 美元 |
| 第 3 天收盘后 | 收盘价 54。均线为 (48 + 51 + 54) ÷ 3 = 51。54 高于 51，目标为 1 份，提交买入 1 份的模拟订单。 | 0 份，100 美元 |

## W10D02　逐日手算均线、持仓与账户价值

本课从 W10D01 的账本继续，把每天的信号、实际交易和账户估值串起来，为下一课的 Python 实现准备人工核对表。2026-11-21 开课，本轮仅讲解和发题，尚无本课独立作答。

### 每天按什么顺序记账

沿用虚构 ETF、连续交易日及三日均线规则：收盘价高于均线时目标为 1 份，等于或低于时目标为 0 份。收盘后取得价格才生成信号；需要交易时提交模拟订单，按下一交易日开盘价全部成交。现金足够才买入，不借款、不卖空。本题所列买入价格均可由账户现金支付。费用、税费、现金利息均为零，无分红、拆股或出入金。现金在成交时更新，本算例不另拆结算状态；这些都是教学条件，不是实际成交保证。

1. **开盘先处理昨天的订单。** 买入时现金减少、份数增加；卖出时现金增加、份数减少；没有订单就保持。只有本题约定的开盘时点成交，不能看到今天的收盘价后再回头决定早上的交易。
2. **收盘给实际持仓估值。** 账户总价值 = 现金 + 实际持有份数 × 当天收盘价。价格变化可以改变持仓市值，即使当天没有交易，现金也未改变。
3. **取得收盘价后，再算均线和新目标。** 要交易的份数 = 目标份数 − 实际份数。结果为 +1 就安排买 1 份，为 −1 就安排卖 1 份，为 0 就不下单。新目标不会立即改变实际持仓或现金。

### 完整示范：复用上节第 3、4 天

第 1–3 天收盘价为 48、51、54 美元/份。第 3 天收盘后三日均线是 (48 + 51 + 54) ÷ 3 = 51 美元/份。54 > 51，目标为 1 份；实际为 0 份、现金 100 美元，因此提交买入 1 份的模拟订单。

第 4 天开盘价为 55 美元/份，订单成交：现金 = 100 − 1 × 55 = 45 美元，实际持仓 = 1 份。第 4 天收盘价为 57 美元/份：

- 账户总价值 = 45 + 1 × 57 = 102 美元。现金仍是 45 美元。
- 新均线 = (51 + 54 + 57) ÷ 3 = 54 美元/份。
- 57 > 54，目标仍为 1 份；目标 1 − 实际 1 = 0，故不再买入。

信号中的“1 份”表示希望总共持有 1 份。是否新增交易，要和账户里已有的份数比较。

## W10D03　用 Python 实现三日均线策略

本课把 W10D02 已验收的手算账本变成程序。程序用于重复执行规则、保留中间状态并与手算对照；一次输出一致不证明策略有投资优势。这里仍然只有虚构价格的教学账本，没有接入行情或交易账户。

### 输入与输出

[实现](../../src/moving_average.py)中的 `sma_ledger` 返回按交易日排列的账本列表，每行是一个字典。`SMA` 是简单移动平均的英文缩写，本课固定使用三个收盘价。调用示范：

```python
from src.moving_average import lesson_days, sma_ledger

days = lesson_days()
ledger = sma_ledger(98, [57, 54], days)
```

- `98` 是第 6 天开盘旧卖单已完成后的现金，起点空仓、没有待成交订单，不重复执行旧卖单。整个连续账户最初投入仍为 100 美元。
- `[57, 54]` 是第 4、5 天已知的收盘价，只给均线提供历史，不重放此前交易。
- `lesson_days()` 每次给出一份新的练习输入，内容就是下面四行。`day` 是连续交易日序号，`open` 为开盘价，`close` 为收盘价，价格单位均为美元/份。

| day | open | close |
| --- | --- | --- |
| 6 | 53 | 57 |
| 7 | 58 | 60 |
| 8 | 59 | 57 |
| 9 | 56 | None |

Python 列表从下标 0 开始，因此 `days[0]` 是第 6 天，`days[0]["close"]` 取到 57。`None` 表示本例观察明确停在第 9 天开盘后，没有第 9 天收盘观测；不把它当作 0、沿用旧收盘价或生成新信号。程序仅允许最后一行如此结束，缺少必要字段或中间缺失收盘价会报错。

返回字段：`day` 为交易日序号，`phase` 为观察时点（`close` 收盘、`open` 开盘），`trade` 为当天开盘成交份数（买入为正、卖出为负），`sma` 为三日均线（美元/份），`target` 为当天收盘新目标份数，`shares` 为实际份数，`cash` 为美元现金，`total_value` 为美元账户总价值。第 9 天只有开盘行，`sma/target` 为 `None`，表示没有当天收盘计算结果。

### 代码怎样保持时间顺序

账户初始化一次：`cash = 98`、`shares = 0`、`target = 0`；之后每个交易日沿用上一个交易日结束时的变量值。最初没有待成交订单，所以首行开盘交易份数为 0。

对已经凑齐三个收盘价且当天有收盘观测的交易日，下面是核心顺序。完整函数另有输入、历史长度、资金和终点检查：

```python
# 开盘：target仍是上一天收盘得到的目标。
trade = target - shares
cash = cash - trade * day["open"]
shares = shares + trade

# 收盘：现在才能加入今天的收盘价，并决定下一开盘的目标。
history.append(day["close"])
history = history[-3:]
average = sum(history) / 3
target = 1 if day["close"] > average else 0
total_value = cash + shares * day["close"]
```

`append` 把当天收盘价加到列表末尾；`history[-3:]` 保留最后三个值。`sum(...) / 3` 对这三个价格取平均。条件表达式在收盘价高于均线时给 `target` 赋值 1，否则赋值 0。`target` 的更新只影响下一次循环的开盘交易，当前实际份数不会随之改变。

现金公式兼顾买卖：买入 `trade = +1` 时减去买款；卖出 `trade = -1` 时减去负数，相当于加上卖款；`trade = 0` 则现金与份数都不变。代码在买入前检查资金，资金不足就报错停止，不借款或假装成交。

### 完整示范：程序怎样走完第 7 天

上一天收盘留下 `target = 1`、`shares = 0`、`cash = 98`。第 7 天开盘价 58：

1. `trade = 1 - 0 = 1`，本次买入 1 份。
2. `cash = 98 - 1 * 58 = 40`，`shares = 0 + 1 = 1`。
3. 收盘时把 60 加入历史，取最后三个价格 `[54, 57, 60]`，算得均线 57。
4. 收盘价 60 高于 57，新 `target = 1`；实际份数仍是 1、现金仍是 40。
