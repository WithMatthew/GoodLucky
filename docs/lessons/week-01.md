## 第一课安排

前 10 分钟讨论你想通过投资实现什么，允许回答“不确定”；随后 15 分钟解释储蓄、投资、期限和流动性。中间 25 分钟做下方目标卡练习，最后 10 分钟复述并记录疑问。今天不需要提供真实资产、收入或账户信息。

储蓄通常帮助你保留将来要用的钱；投资则让资金承担一定风险，以追求未来回报。做决定前要先知道资金什么时候会用到，以及发生损失会不会影响用途。应急资金和长期目标应分开考虑。[SEC 储蓄与投资基础](https://www.investor.gov/build-wealth-over-time-through-saving-and-investing)

本课只要求理解三个词：

- 本金：在某项投资中投入的资金。
- 投资期限：预计多久后需要使用这笔钱。
- 流动性：把资产变成可使用现金的便利程度，需同时考虑所需时间与可能付出的价格代价。

用下面的虚构家庭做练习，不需要选择金融产品：

| 用途 | 虚构金额 | 预计使用时间 | 请你回答 |

| 意外支出备用金 | 12,000 元 | 时间不确定 | 为什么随时可用很重要？ |

## 第二至第四课的练习素材

以下都是教学假设，不代表某项产品的收益、当前通胀或未来预测。先自己计算，再让 Codex 核对。

第二课在没有追加或取出资金、没有费用与分红的简化条件下，使用 `收益率 = (期末价值 - 期初价值) / 期初价值`，完成三组练习：1,000 变成 1,080；5,000 变成 4,600；10,000 变成 10,400。比较第一组与第三组的盈利金额和收益率。存在现金流时不能直接套用这个简化公式。

第三课假设本金为 1,000，分别经历 `[0.10, -0.10]` 和 `[-0.20, 0.25]` 的两期收益。先预测是否回本，再编写 `compound_value(principal, returns)` 按期相乘核对。要能解释为什么通常不能直接把两期收益率相加。当天由 Codex 检查 Python 是否可用；本练习只需标准库。

第三课辅助程序见 [compound.py](../../src/compound.py)。先完成预测和手算，再在仓库根目录执行：

```powershell
python src/compound.py
```

已验证环境为 Python 3.11.9，无第三方依赖，无须安装软件包。程序分别核对上述 A、B 两组虚构算例，不连接行情或账户。`principal` 是期初本金，`returns` 是按时间排列、用小数表示的每期收益率；函数返回最终金额。假设没有追加或取出资金，没有费用与分红，资金全部留在投资中；只接受约定范围内的教学输入，使用浮点数计算并仅在展示时保留两位小数。程序运行成功不代替用户对输入、逐期更新和结果的解释。

第四课假设一年名义收益率为 5%，同期通胀为 3%，先判断购买力有没有增加，再使用 `(1 + 名义收益率) / (1 + 通胀率) - 1` 核对。将名义收益率改为 2%，解释结果为何改变。

## 第 5 课小测题（W01D05）

以下均为虚构情景，不是当前数据或未来预测。可以使用计算器，请按 1–5 作答，写出计算过程或判断理由；百分比需要舍入时保留两位小数。第 2–5 题均假设期间没有追加或取出资金，没有税费与分红，全部资金留在投资中。

1. **期限与资金用途**：一个虚构家庭留有 4,000 元，一个月后必须用它支付房租。有人打算把这笔钱投入可能短期大跌的资产，并说：“长期平均收益高，等上涨了再付房租。”这项安排的问题是什么？
2. **盈亏与收益率**：期初投入 2,400 元，一年后价值为 2,580 元。盈亏金额和这一年的收益率分别是多少？
3. **复利**：期初本金 1,500 元，第一期上涨 20%，第二期下跌 10%。分别计算第一期末金额、第二期末金额和两期总收益率。
4. **亏损后回本**：1,000 元下跌 25% 后，还剩多少？从此时的金额再上涨 25%，能否回本？从下跌后的金额出发，实际需要上涨多少百分比才能回到 1,000 元？
5. **购买力**：假设一年名义收益率为 4%，同期通胀率为 6%。实际收益率约为多少？购买力增加还是减少？

每题 1 分，题内的关键计算及解释应完整。小测至少答对 4 题，并完成后续程序演示与独立解释，才通过本周验收。先提交作答，再核对答案；部分作答、提示和补正情况记入学习进度，不能当作未经提示的首答成绩。程序演示在小测反馈后进行，使用已有 `compound_value` 函数。
